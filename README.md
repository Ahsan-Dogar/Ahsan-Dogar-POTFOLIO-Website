## ✨ Features

- 🎬 **Cinematic loading sequence** — an elegant GSAP timeline intro before the site loads
- 🌌 **Immersive 3D background** — Three.js-powered visuals behind every section
- 📜 **Scroll-triggered animations** — GSAP `ScrollTrigger` & `ScrollToPlugin` for smooth, professional motion
- 🤖 **AI Chatbot** — Gemini-powered assistant that interacts with visitors
- 🧩 **Complete portfolio sections** — Navbar, Hero, About, Skills, Projects, Services, Contact & Footer
- 💎 **Ultra-luxury aesthetic** — premium visual design, dark theme, and buttery-smooth interactions
- 📱 **Fully responsive** — flawless on desktop, tablet, and mobile

## 🚀 Quick Start

**Prerequisites:** Node.js

```bash
# 1. Clone the repository
git clone https://github.com/Ahsan-Dogar/Ahsan-Dogar-POTFOLIO-Website.git

# 2. Install dependencies
cd Ahsan-Dogar-POTFOLIO-Website
npm install

# 3. Set your Gemini API key
#    Create a .env.local file and add:
#    GEMINI_API_KEY=your_key_here

# 4. Run the dev server
npm run dev
```

Open **http://localhost:5173** in your browser.
